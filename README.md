# AI-Based Adaptive LED Brightness Controller

An Arduino project where a small machine learning model (linear regression)
adjusts LED brightness automatically based on ambient light measured by an LDR.

## Files
- `adaptive_led.ino`: Arduino code that runs the model
- `train_model.py`: Python script that trains the model and gives the weights

## Hardware
Arduino Uno, LDR, LED, resistors, breadboard
